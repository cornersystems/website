# Corner Systems AI Website

A polished one-page React/Vite website for Corner Systems AI, focused on automation and lead systems for combat sports gyms.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The main site lives in `src/App.jsx` and `src/styles.css`. The generated hero image is stored at `public/assets/combat-gym-systems-hero.png`.
